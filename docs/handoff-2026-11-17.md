## How Brood is built

- The browser app is React + Vite. `src/main.jsx` holds the UI, the tour and the help text. `src/audio-engine.js` holds the engine, songs and fades. `src/brood-worklet.js` is the AudioWorklet DSP.
- The plug-in is JUCE. `native/dsp/brood.h` is the C++ DSP core, kept sample-for-sample identical to the worklet. The parity test checks this. `native/plugin/PluginEditor.cpp` and `PluginProcessor.cpp` hold the plug-in UI, help and describe text.
- The screen fitting:
  - Browser: `ScreenLine` and `HelpText` in `src/main.jsx` narrow, then shrink, then wrap.
  - Plug-in: kit `drawReadout` in `kit/include/kit/Look.h` does the same.
- Canvas sizes:
  - Desktop: 1200x820, with a 140 px tour strip below it.
  - Phone: 390 wide, 1676 tall.

## How the site's copy of Brood is built

The site hosts Brood at `/brood-app/` with a small patch on top.

1. Make a clean copy of the Brood commit (`git archive <commit>`) and symlink `node_modules` into it.
2. Apply `jackherz-site/brood-app/site-integration.patch` (about 69 lines). It adds:
   - the audio-started postMessage
   - fit-to-width when embedded (`html.embedded`)
   - demos loaded from `BASE_URL/demos/`
3. Build with `npx vite build --base /brood-app/`.
4. Copy the build into `brood-app/`. Keep `demos/`, `songs.json` and `licenses/`.
5. Regenerate the patch against the new Brood commit. Check that the patched copy equals the build source with `cmp`.
6. Put the new Brood commit hash in `brood-app/SOURCE.md`.
7. If you edit the site's `app.js` or `styles.css`, bump the `?v=` tags in `index.html` to the first 8 hex of the file's sha256.

**Local preview:**

- `python3 -m http.server 8765 --bind 127.0.0.1 --directory <site>` works, but it has no Range support, so songs won't seek.
- To test seeking, use a Range-capable server. The last one lived in the old session's scratchpad (`rangeserver.cjs`) and may be gone. A few lines of Node will replace it.

**Site details worth knowing:**

- `functions/api/download.js` holds the exact R2 paths for the installers and falls back to searching the bucket. If installer file names change, update this file and the download names in `app.js`.
- `brood-app/songs.json` lists 16 songs (id, title, album, src, duration, and an optional `short`). Brood puts them in the DEMO stepper after the loops.
- Song handover: if the header player is playing when you open Brood, Brood carries on the same song through `?song=<id>&t=<s>&play=1`. The header player is hidden on the Brood page.
- The volume slider is hidden on iPhones and iPads (detected by user agent, including iPads that present themselves as a Mac), because iOS ignores web volume. The device buttons set the volume there. It shows everywhere else.
